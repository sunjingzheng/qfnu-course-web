# QFNU 选课控制台

一个只运行在本机 `127.0.0.1` 的 Web 控制台，依据 [接口文档](qfnu-jiaowu-api.md) 登录曲阜师范大学强智教务系统、搜索目标课程、提交选课并确认结果。

## 功能

- 支持必修、选修、本学期计划、专业内跨年级、计划外和公选课六个已知模块。
- 登录后可一次加载六个模块返回的全部可选课程，由用户从列表添加监控目标，无需填写课程 ID。
- 显示课程号、名称、教师、学分、开课单位、类别、余量、时间、地点、校区、教学班、实验分组和冲突信息。
- 普通课直接提交；讲课加实验课程按接口文档一次提交最终组合请求。
- 内置 OCR 随控制台启动并自动识别登录验证码；多次识别失败时，网页会显示验证码供手动输入。
- 学号和自动化选项保存在 `config.json`，密码保存在 macOS 钥匙串服务 `qfnu-course-web`。
- 默认选择轮次列表中的当前轮次，并在运行期间检测变化后自动切换。
- 可配置多个目标、优先级、教师、教学班、星期、节次、实验分组和互斥组。
- “按课程编号抢课”只需填写选课模块和课程编号（如 `G200511771`）；程序自动查询教学班并过滤冲突、已选和已满记录。
- 运行参数固定为每秒最多 `5` 次请求、每 `0.1` 秒扫描一轮且不设最长运行时间。
- 等待期间定期检查会话；登录失效最多自动恢复三次，异地登录会停止，限流会退避。目标未成功时会持续请求，直到用户停止。
- 同一互斥组内一门课程确认成功后，其余目标会自动跳过。
- 密码不会写入配置、浏览器存储、接口响应或日志。

## 安装与启动

需要 Python 3.11 或更高版本。

```bash
git clone https://github.com/sunjingzheng/qfnu-course-web.git
cd qfnu-course-web
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m qfnu_course_web
```

程序会显示并打开类似 `http://127.0.0.1:8765` 的本地地址。停止程序时在终端按 `Ctrl+C`。使用固定端口但不自动打开浏览器：

```bash
.venv/bin/python -m qfnu_course_web --port 8765 --no-browser
```

## 操作流程

1. 打开“自动化设置”，填写学号并保存设置，再输入密码并点击“保存密码”。macOS 可能会要求允许访问钥匙串。
2. 内置 OCR 会随控制台一起启动，无需填写服务地址。可在自动化设置中调整识别尝试次数。
3. 点击“启动自动工作流”。程序会自动登录并选择轮次；需要人工验证码时页面会自动弹窗。
4. 登录后，在“全部可选课程”区域选择轮次并点击“加载全部可选课”。程序按顺序查询六个模块，并展示接口返回的全部课程详情。
5. 使用课程名、课程号、教师或模块筛选，然后点击课程旁的“添加到监控”。带实验学时的课程应从具体实验分组行添加。
6. 需要按编号直接监控时，点击“按课程编号抢课”，只填写模块和课程编号。若同一编号有多个可选教学班，程序会逐个尝试。
7. 自动工作流会立即启动并跟随当前轮次。页面显示认证阶段、所选轮次、目标状态和网络事件；未成功目标会持续重试，点击“停止”才会主动结束。

部分教务模块在空关键字查询时可能返回空列表，这是教务接口本身的行为。页面会分别显示六个模块的返回数量或错误，不会用大量猜测关键字的请求绕过这一限制。

运行时不要关闭启动控制台的终端。进程退出后登录会话和任务状态会清除，钥匙串密码与 `config.json` 会保留。

## 自动化配置

首次启动会在项目根目录创建权限为 `0600` 的 `config.json`。可参考 [config.example.json](config.example.json)。配置包含：

- `account.username`：学号。
- `auth.ocr_url`：为旧配置兼容保留，启动时会清空；自动登录统一使用内置 OCR。
- `auth.ocr_attempts`、`auth.keepalive_seconds`：内置 OCR 尝试次数和会话检查间隔。
- `selection`：为兼容旧配置保留，服务端会固定为空轮次关键字、立即启动、每秒 `5` 次请求、`0.1` 秒扫描间隔、无最长运行时间且不要求学期 ID。运行中每轮扫描都会检测并切换到当前轮次；轮次列表为空时停止旧轮次课程请求并持续监听，恢复后自动进入新轮次继续运行。
- `targets`：从目录添加的目标或按课程编号添加的目标。

密码使用 `/usr/bin/security` 保存到 macOS 钥匙串，不属于 `config.json`。删除密码可在自动化设置中操作。

## 旧版 YAML 导入

[courses.example.yaml](courses.example.yaml) 可直接作为导入格式参考。配置只包含运行参数和目标课程，禁止存放账号、密码、Cookie 或票据。导入时未知字段会被拒绝。

模块配置名：

| 配置名 | 模块 |
| --- | --- |
| `bxxk` | 必修选课 |
| `xxxk` | 选修选课 |
| `bxqjhxk` | 本学期计划选课 |
| `knjxk` | 专业内跨年级选课 |
| `fawxk` | 计划外选课 |
| `ggxxkxk` | 公选课选课 |

辅修专业模块没有经过接口文档验证，因此没有内置猜测端点。

## 登录编码说明

接口文档中的 `encoded` 示例和文字算法存在一处矛盾。按照文字算法与强智前端常见实现，原始字符串中的每个字符都会保留，因此 `u%%%p`、`scode=ABC123`、`sxh=201` 的结果为 `uAB%%C%p`；文档示例少写了一个 `%`。本项目采用文字算法。

