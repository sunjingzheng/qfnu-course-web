# 曲阜师范大学教务选课 Web 控制台设计

## 目标

实现一个运行在 `127.0.0.1` 的 Python 3.11 Web 控制台，依据 `qfnu-jiaowu-api.md` 登录教务系统、进入选课轮次、搜索目标课程、提交选课并确认结果。控制台支持文档中已知搜索与操作端点的六个模块，允许同时配置多门目标课和候选教学班优先级，并实时展示课程、任务和网络状态。

工具用于个人账号的正常选课操作。全局请求速率默认每秒 2 次，配置上限为每秒 2 次；遇到限流、服务器故障、会话失效或异地登录时退避或停止。不会实现持续每秒 20 次请求。

## 范围

### 已支持模块

| 配置名 | 搜索端点 | 操作端点 | 入口 |
| --- | --- | --- | --- |
| `bxxk` | `xsxkBxxk` | `bxxkOper` | `comeInBxxk` |
| `xxxk` | `xsxkXxxk` | `xxxkOper` | `comeInXxxk` |
| `bxqjhxk` | `xsxkBxqjhxk` | `bxqjhxkOper` | `comeInBxqjhxk` |
| `knjxk` | `xsxkKnjxk` | `knjxkOper` | `comeInKnjxk` |
| `fawxk` | `xsxkFawxk` | `fawxkOper` | `comeInFawxk` |
| `ggxxkxk` | `xsxkGgxxkxk` | `ggxxkxkOper` | `comeInGgxxkxk` |

辅修专业模块在接口文档中没有实测搜索和操作端点，因此不内置猜测值。模块表集中定义，取得真实端点后可直接扩展。

### 不在范围内

- 绕过验证码、限流、访问控制或账号安全机制。
- 对服务持续发送高频请求。
- 自动处理报志愿、投积分以及未实测的选课验证码提交协议。
- 自动选择存在冲突或限选提示的候选课程。

## 使用方式

命令行入口为 `python -m qfnu_course_web`，服务只监听 `127.0.0.1`，启动后在默认浏览器打开控制台。账号和密码由登录表单输入，只保存在当前 Python 进程内，不写入配置、浏览器存储、日志或异常文本；也允许用 `QFNU_USERNAME` 预填账号，但密码始终需要当次输入。

页面支持导入和导出 YAML 目标配置，配置包含：

- 轮次 ID，可省略并从列表中选择唯一可用轮次。
- 学期 ID，用于最终结果确认。
- 轮询间隔与总运行时长。
- 多个目标课，每项包含模块、课程号或名称、教师、教学班 ID、实验分组、时间条件以及优先级。
- 可选 OCR 服务地址。未配置时在登录区直接显示验证码图片并读取用户输入。

候选匹配优先使用不可变 ID。只给课程名或教师时，若匹配到多个同优先级候选，工具列出候选并停止，避免误选。

## 页面结构

### 顶部状态栏

显示登录状态、选课轮次、会话状态、运行或暂停状态、当前全局请求速率以及退避倒计时。状态变化用图标、文字和颜色共同表达，避免只依赖颜色。

### 目标课程表

以紧凑表格显示模块、课程号或名称、教师、教学班、实验分组、时间条件、优先级和任务状态。支持新增、编辑、删除、启用、停用以及导入导出；编辑在侧栏表单完成，字段校验错误显示在对应输入项旁边。

### 课程候选表

显示课程号、名称、教师、教学班、实验分组、余量、已选人数、容量、上课时间、地点、校区、冲突说明及匹配结果。支持按目标筛选和查看原始业务提示。只有唯一、无冲突且字段完整的候选才能进入自动提交。

### 任务与事件区

任务视图显示每个目标的等待、搜索、可提交、提交中、确认中、成功或失败状态。事件流按时间显示脱敏后的请求状态、退避、业务消息和停止原因；不显示 Cookie、票据、密码、验证码或完整选课 URL。

### 操作

提供登录、退出、开始、暂停、单次刷新、查看候选、确认单次提交、导入和导出。危险动作使用明确的课程名称和教学班信息进行确认。页面关闭不终止后台任务，重新打开后恢复显示当前内存状态；进程退出后任务和凭证全部清除。

## 架构

### `config`

读取表单或 YAML，验证模块名、速率、目标课程和运行时长。任何未知字段都报错，防止拼写错误被静默忽略。速率限制为 `0.1..2.0` 次/秒。

### `web`

提供本地 HTML 页面、JSON 控制接口和服务器发送事件流。浏览器只与 `127.0.0.1` 通信；写操作要求进程启动时生成的随机会话令牌和同源请求。页面刷新后从服务端内存重建状态，不使用浏览器持久化存储保存凭证。

### `scheduler`

在单个后台任务中管理搜索、提交、确认、暂停和停止。任何时刻只有一个网络请求在途。开始操作是幂等的，重复点击不会创建第二个任务；暂停后不再启动新请求，当前请求结束后进入暂停态。

### `session`

封装 `httpx.Client`、Cookie、固定 User-Agent、同源登录重定向、超时与响应大小限制。所有请求经过同一个全局限速器。日志仅记录方法、路径、状态码和等待时间，不记录 Cookie、票据、验证码、账号或查询字符串中的教学班参数。

### `auth`

执行初始化、获取验证码、获取 `scode/sxh`、生成 `encoded`、提交登录和登录状态验证。登录阶段只跟随同源重定向，状态验证禁止自动重定向。验证码图片以内存数据 URL 发送给本地页面，不落盘；识别失败最多重新开始登录两次。

### `catalog`

获取轮次、进入轮次和模块，按配置搜索课程并把 JSON 行解析成统一的 `CourseCandidate`。检测响应被登录页替换、异地登录文本、非 JSON 响应和字段缺失。

### `matcher`

按目标 ID、课程号/名称、教师、星期节次、实验分组和优先级筛选候选。`ctsm` 非空、明确无余量或数据不完整的候选不会自动提交。带讲课和实验学时的课程必须找到同一 `jx02id` 的讲课班和指定实验班。

### `enrollment`

普通课只提交 `kcid`、`jx0404id` 和时间戳。带实验学时的课程按文档一次提交最终请求，其中 `yxjx0404id` 为讲课班、`jx0404id` 为实验班。只有消息精确表示“选课成功”才视为提交成功；“还有[...]需要选”属于未完成。

### `verification`

成功响应后调用结果列表接口，按课程编号或名称确认记录存在。确认后将目标标为完成；全部目标完成或超过总运行时长后退出。

## 调度与停止条件

主循环按目标优先级逐项搜索，目标间共用令牌桶，默认每秒 2 次请求且无并发。未找到名额时等待带随机抖动的轮询间隔。

- `429`：尊重 `Retry-After`，没有该响应头时从 30 秒开始指数退避。
- `5xx` 或网络超时：指数退避并加入抖动，连续五次后停止。
- `401/403`、登录页替换或会话验证失败：停止并要求重新登录。
- 异地登录：立即停止。
- 明确业务失败，如冲突、限选、重复选课：记录服务端消息并停止该目标。
- 成功：立即验证结果并停止该目标的所有后续请求。
- `SIGINT`：完成当前请求后退出，不再发新请求。
- 页面断开：任务继续执行并受最长运行时间约束；重新连接事件流后发送完整状态快照。

## 安全与数据处理

- 密码由本地登录表单传入，运行期间仅保存在服务端内存，不回传给页面、不落盘。
- 验证码图片只保存在内存中，登录结束后释放。
- 禁止跨源重定向，拒绝把 Cookie 发送给非教务域名；OCR 只接收验证码图片的 base64，不共享会话信息。
- 本地服务只绑定 `127.0.0.1`，设置严格的同源和内容安全策略，并为写操作校验随机会话令牌。
- 默认 HTTP 基础地址来自接口文档。若站点提供 HTTPS，可由配置显式切换；不关闭 TLS 校验。
- 日志默认输出到终端，敏感请求参数统一脱敏。

## 测试

测试全部使用 `httpx.MockTransport` 或等价本地伪响应，不访问真实教务系统。

- `encoded` 插入算法的示例与边界条件。
- 同源与跨源重定向判断。
- 登录成功、验证码错误、密码错误、登录页替换和异地登录。
- 六个模块的 URL 映射与查询参数。
- 普通课程和讲课加实验课程的候选匹配。
- 普通课提交和带实验学时的一次提交。
- 成功消息、未完成消息、业务失败和结果确认。
- 全局限速、`Retry-After`、指数退避、连续失败停止与成功后零额外提交。
- 页面状态接口、事件流重连、重复开始幂等、暂停和进程退出清理凭证。

## 验收标准

1. 使用示例配置和伪服务可从 Web 页面跑通登录、搜索、提交、确认完整流程。
2. 六个已知模块生成的入口、搜索和操作路径与接口文档一致。
3. 任意网络请求均经过全局限速器，配置无法超过每秒 2 次。
4. 日志和异常中不出现密码、Cookie、票据或完整 `encoded`。
5. 选课成功后不会继续搜索或提交同一目标。
6. 全部自动化测试通过，且测试不会连接 `zhjw.qfnu.edu.cn`。
7. 页面可查看候选课程、目标状态、会话状态、请求速率、退避倒计时和脱敏事件流。
8. 重复点击开始不会创建重复任务，暂停后不会启动新请求，页面重连可恢复当前状态。
