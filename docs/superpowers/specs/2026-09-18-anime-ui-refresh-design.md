# 月夜电波控制台 UI 改版设计

## 目标

将现有 QFNU 选课控制台改造成原创二次元未来月夜风格，同时保留现有信息密度、操作位置和响应式行为。视觉参考来自太空歌姬、月面舞台和复古科幻终端的共同氛围，不复刻具体作品角色、标志或海报。

## 背景表现

- 不调用生图模型，不引入外部图片请求。
- 使用 CSS 绘制星轨、月面切线、远景网格和扫描线，营造未来月夜与二次元舞台氛围。
- 装饰层固定铺满视口并设置为 `aria-hidden`，不进入键盘焦点或遮挡正文。
- 桌面端在右侧保留较强视觉焦点；移动端降低装饰对比，确保内容与固定操作栏清晰。

## 视觉系统

- 基础色使用月白、冰蓝和冷灰；玫红用于主要操作，电青用于状态和焦点。
- 成功、警告和错误继续使用绿、黄、红语义色，不能只依赖颜色表达状态。
- 内容面板采用高不透明度的亮色玻璃表面、细边框和轻微模糊，表格正文使用深色文字保持清晰对比。
- 圆角不超过 6px；不改变表格列、表单字段、按钮功能或页面信息架构。
- 标题栏改成窄幅“月面电波终端”风格，产品名仍为 `QFNU 选课控制台`。

## 组件

- 状态条显示会话、轮次、自动化和速率，采用仪表式分隔与状态光标。
- 命令栏保留启动、停止、设置和按课程编号抢课操作，主操作使用玫红强调。
- 课程目录、目标课程和运行事件保持现有布局；增加清晰的行悬停、焦点和活动状态。
- 对话框沿用同一亮色视觉系统，验证码图片保持高对比白底。
- 手机端保持固定底部操作栏，表格继续使用卡片化行布局，但不增加嵌套卡片。

## 动效与可访问性

- 页面加载使用一次轻量淡入；运行状态可以使用低强度呼吸效果。
- 背景扫描线必须很淡，不能覆盖表格文字或验证码。
- `prefers-reduced-motion: reduce` 时关闭非必要动画。
- 所有现有标签、焦点轮廓、ARIA 属性和键盘操作继续保留。

## 验证

- 运行现有 UI 合约测试、完整 Python 测试、Ruff 和 JavaScript 语法检查。
- 使用 Playwright 检查 1440x900 桌面和 390x844 手机视口。
- 检查背景加载、文字对比、表格横向滚动、对话框、固定操作栏和控件无重叠。
